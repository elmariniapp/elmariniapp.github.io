Comment je travaille.

Le même déroulé pour chaque mission, pour que vous sachiez toujours où on en est.

  1. Reproduire

    Je fais apparaître le problème sur un vrai appareil, avec les mêmes conditions que vos utilisateurs.

  2. Trouver la cause

    Je remonte jusqu'à l'origine plutôt que de masquer le symptôme.

  3. Corriger

    Je modifie la bonne partie du code et j'ajoute un test pour que le bug ne revienne pas.

  4. Vérifier et livrer

    Je teste sur Android et iOS, puis je vous livre la version prête à publier.

Dites-moi ce qui bloque.

Quelques lignes suffisent : ce qui se passe, sur quelle plateforme, et depuis quand. Je vous réponds avec une première lecture et le créneau le plus proche.
